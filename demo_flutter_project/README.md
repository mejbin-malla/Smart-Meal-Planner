# Demo Flutter Project

This is a simple Flutter application that displays "Hello World" on the screen.

## Getting Started

To run this project, you need to have Flutter installed on your machine. Follow the instructions below to set up and run the application.

### Prerequisites

- Flutter SDK
- Dart SDK
- An IDE (like Android Studio, VS Code, etc.)

### Installation

1. Clone the repository or download the project files.
2. Navigate to the project directory:
   ```
   cd demo_flutter_project
   ```
3. Get the dependencies:
   ```
   flutter pub get
   ```

### Running the Application

To run the application, use the following command:
```
flutter run
```

You should see a screen displaying "Hello World". 

### Project Structure

- `lib/main.dart`: The entry point of the application.
- `pubspec.yaml`: Configuration file for the Flutter project.
- `README.md`: Documentation for the project.
